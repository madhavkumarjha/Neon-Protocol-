# v1_MVP_SCOPE.md — Version 1 Scope Specification

> **Target Goal:** Deliver a tight, highly playable 2D cyberpunk endless survival arcade shooter for web and mobile browsers.

---

## 1. V1 Deliverables Checklist

- [x] Full documentation foundation (`README.md`, `AGENT.md`, `docs/` kit).
- [ ] Phaser 3 + TypeScript + Vite project scaffolding.
- [ ] Core Arena Gameplay Scene with 60 FPS target.
- [ ] Dual Virtual Joystick Touch Overlay & WASD Mouse/Auto-fire Desktop Controls.
- [ ] 5 Weapons (Plasma Pistol, Arc Shotgun, Laser Rifle, EMP Grenade, Pulse Blade).
- [ ] 4 Enemy Types (Scout, Enforcer, Hacker, Drone) + 1 Boss (Cyber Overlord).
- [ ] Wave Spawner with escalating difficulty curves.
- [ ] Between-wave 3-Choice Upgrade Modal.
- [ ] Global Leaderboard connected to Supabase using anonymous `device_id`.
- [ ] Audio SFX & Synthwave background track with browser unlock logic.

---

## 2. Non-Goals for V1

- No scripted story campaign.
- No LLM / AI dynamic content.
- No co-op or PvP multiplayer.
- No monetization or microtransactions.
