# v3_CAMPAIGN.md — Version 3 Scope Specification (Campaign & Codex)

> **Target Goal:** Introduce a structured Campaign Mode featuring scripted stage objectives, environmental hazards, and unlockable codex lore.

---

## 1. Planned V3 Features

1. **Scripted Stage Campaign:**
   - 12 distinct cyberpunk sectors (Neon Alleyways, Corporate Towers, Underground Cyber-Grid).
2. **Environmental Hazards:**
   - Laser grids, acid pools, conveyor belts, and security turrets.
3. **Cyberpunk Codex & Lore System:**
   - Minimalist unlockable text logs detailing corporate faction history and sector lore.
